## 🚀 How to Run & Preview

### Option 1: Open Directly in Any Browser
- Double-click `index.html` or right-click and choose **"Open with Chrome"** / **"Open with Edge"**.
- Since it uses standard CDN links for Bootstrap 5.3 and Bootstrap Icons, it requires **zero installation** or node packages!

### Option 2: Deploy to GitHub Pages (Free)
1. Initialize git in this folder:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Adarsh portfolio"
   ```
2. Push to a repository on GitHub (e.g. `adarsh-portfolio`).
3. In GitHub repo Settings -> **Pages**, select branch `main` and root `/`.
4. Your site will be live instantly!

### Option 3: Deploy to Vercel or Netlify
- Drag and drop the `adarsh-portfolio` folder directly into [Netlify Drop](https://app.netlify.com/drop) or connect to Vercel for free hosting with automatic HTTPS.
